# pekozlov-cv

Резюме на Vue 3, Vite и TypeScript. Единственный источник данных — **`src/data/cv.json`**: из него строятся сайт, предпросмотр и PDF. Текст можно редактировать вручную или в локальной админке.

## Установка

Нужны Node.js **22.18+**, pnpm и Git. Chromium используется для генерации PDF, устанавливается один раз:

```bash
pnpm install
pnpm exec playwright install chromium
```

На Linux для установки системных зависимостей Chromium используйте `pnpm exec playwright install --with-deps chromium`.

## Локальная админка

Из каталога репозитория:

```bash
pnpm admin
```

Откройте **http://127.0.0.1:4174/admin**. Порт можно изменить: `ADMIN_PORT=4175 pnpm admin`.

- Каждая работа — отдельная карточка с компанией, должностью, датами, описанием, командами / проектами и достижениями. Работы и достижения можно добавлять, удалять и переставлять.
- У работы есть необязательный **сайт компании** (`companyUrl`, полный адрес с `https://`). Название становится ссылкой на сайте и в PDF. При сохранении сервер ищет favicon на сайте; если прямое скачивание недоступно, использует сервис favicon Google. Полученная иконка сохраняется в JSON как `companyLogo` и повторно используется без внешних запросов при просмотре сайта и генерации PDF. Без URL или доступного favicon показывается портфельчик. При смене URL загружается новая иконка; при удалении URL иконка удаляется. Неудачная загрузка не блокирует запись резюме.
- Также редактируются имя, должность в шапке, путь к фотографии в `public/`, контакты, описание, стек, образование и языки.
- Изменения **автоматически записываются в `src/data/cv.json` через 0,6 секунды** после ввода, без коммита и push. Незаполненные обязательные поля и некорректные даты не записываются: форма показывает ошибки, предыдущий корректный файл сохраняется.
- **«Сохранить и отправить в Git»** дожидается записи файла, создаёт коммит `Update CV data` только для `src/data/cv.json` и выполняет обычный `git push` текущей ветки в её upstream. Остальные изменения и staged-файлы в этот коммит не попадают. Как и обычный push, команда отправляет и уже существующие локальные коммиты этой ветки.
- Для push должны быть настроены имя и email Git, upstream ветки и доступ к remote через SSH-ключ / credential helper. Интерактивный запрос пароля отключён. Если push не прошёл, локальный файл и созданный коммит сохраняются; исправьте доступ / расхождение веток и нажмите кнопку ещё раз. Force push и автоматический pull не выполняются.
- Если файл изменён извне или другой вкладкой, админка остановит запись и предложит перезагрузку, чтобы не затереть чужие изменения.
- Справа есть живой веб-предпросмотр, мобильный вид и **PDF**, который генерируется из текущего сохранённого файла. Ошибки генерации показываются в форме.

Сервер слушает только `127.0.0.1`. Админка и её API работают только при `pnpm admin`; **в `dist` они не включаются и на GitHub Pages не публикуются**. Остановить сервер — `Ctrl+C`.

## Даты и стаж

У работы задаются `startDate` и `endDate` в формате `YYYY-MM`; `endDate: null` означает «Настоящее время». Подпись периода и стаж вычисляются на фронте. Оба указанных месяца входят в стаж: февраль 2021 — август 2025 → **4 года 7 месяцев**. Работа в одном месяце → **1 месяц**. Для текущей работы расчёт идёт по текущему месяцу браузера и обновляется без пересборки сайта.

## Фронтенд

```bash
pnpm dev
```

Кнопка скачивания в dev-режиме также генерирует актуальный PDF. Для редактирования с живым предпросмотром используйте `pnpm admin`.

Справа от скачивания PDF находится переключатель светлой / тёмной темы. Первоначально используется системная тема, ручной выбор сохраняется в браузере. Компания и период работы отображаются над должностью. PDF всегда остаётся светлым; подпись со ссылкой на конструктор видна только на сайте.

## Сборка и PDF

```bash
pnpm test
pnpm build
pnpm preview
```

`pnpm build` проверяет типы, собирает и предварительно рендерит сайт, затем создаёт **`dist/CV.pdf`** через Chromium / Playwright. PDF использует тот же Vue-компонент и печатные CSS-стили, что и сайт: текст, контакты и опыт берутся из JSON. Готовый PDF **не хранится в Git**.

Отдельные команды:

```bash
pnpm build:site # только сайт, без PDF
pnpm pdf        # создать dist/CV.pdf из уже собранного сайта
```

На опубликованном статическом сайте PDF соответствует данным и текущему месяцу на момент сборки. Чтобы обновить стаж в PDF для текущей работы, пересоберите сайт (можно вручную запустить workflow). Фронтенд рассчитывает этот стаж по текущей дате посетителя.

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` при push в `main` устанавливает Chromium, запускает тесты, собирает сайт вместе с PDF и публикует `dist`. Его также можно запустить вручную на вкладке **Actions**.

В **Settings → Pages** должен быть выбран **Source: GitHub Actions**. Vite использует относительный `base`, поэтому сборка подходит и для публикации в подкаталоге.

## Структура

- `src/data/cv.json` — данные резюме, редактируемые админкой;
- `src/components/Resume.vue` — общий вид для сайта, предпросмотра и PDF;
- `src/lib/experience.ts` — даты, стаж и склонения;
- `admin/` — локальная форма и предпросмотр;
- `scripts/admin.mjs` — локальный сервер, запись файла и Git;
- `scripts/pdf.mjs` — генерация PDF;
- `public/profile.png` — фотография;
- `tests/` — расчёт стажа, проверка и запись данных, Git-публикация на временный локальный remote.
